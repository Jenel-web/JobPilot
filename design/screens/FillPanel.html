Rules this design keeps

Never clicks Submit. No Submit button in the panel; it says "you click Submit yourself". A test will prove no code path clicks it.

Never covers Submit. Docks top right, can be dragged aside, collapses to a 36 px tab.

Opens itself on application pages. When the page looks like an application form (decided by code, no AI) the panel opens in the Ready state; on every other page it stays a collapsed tab.

Bot's browser only. Injected into the bot's own profile (shadow DOM), never into your everyday Chrome.

Same result as the dashboard button. Same steps: read, job post finder, answers, resume picker, fill.

One primary button per view. Fill this page / Filling… / Use this job post and fill. "Fill without resume" fills everything except the resume file; it never picks one for you.

Amber = guess. Flagged fields on the page use the AI-guess style (amber background, amber border, "AI guess, check this").
